# 任务与执行事实

本模块拥有设备配置、标签归属、处方独立参数版本、任务归属/完整快照、事件与删除防重建标识。公开模型在 `models.py`，路由在 `routes.py`，SQL 表在 `tables.py`，事务操作在 `service.py`；`coverage.py` 只提供已完成实机任务的覆盖边界给计划模块。客户端通过生成的 Dart SDK 调用，不导入服务端内部或直接读库。

同长者、同设备最多一个有效任务，由数据库部分唯一索引保证。首次启动同时校验计划当前性、账号/终端、UID 及观察新鲜度；之后保留冻结快照。事件按任务连续序号提交，完全相同的重传幂等，不接受跳号或同序号篡改。累计计数不是逐格实测；全部批次完成后待取盒，就绪事件必须匹配领取时的反馈配置。取消使本次覆盖无效；显式删除级联清除事件并保留不含业务内容的任务 ID 防重建。

锁顺序：设置（计划校验）→ 长者 → 设备/任务。HTTP 成功前由连接依赖提交事务。模块不连接串口、不发送机器命令、不以心跳超时释放任务。硬件选择参数时忽略模拟参数，回退至默认组；模拟执行不推进真实覆盖、不更新实机学习参数。

批次完成后，根据终端上传的启动、脉宽及成功手动设置事件执行 `learning.py`；有效样本、筛选原因、计算结果和来源保存在任务快照。中央参数版本或形态变化时保留结果但不覆盖新值；重复补传不会重复学习。显式删除任务会删除该任务来源的学习参数。历史参数缺少投料形态依据时保留历史并从默认组开始。

验证：仓库根 `scripts/backend.ps1 test`，具体用例在 `apps/api/tests/test_tasks.py`。当前历史接口最多返回最近 200 个任务、事件分页读取；部分结果人工补齐与细粒度覆盖待后续交付。
