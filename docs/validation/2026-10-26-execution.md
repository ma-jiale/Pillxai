# Windows 上机联调版验证

目标：在 NT 分支贯通处方、服务端计划、领取、药盒识别、Windows 本机执行和结果同步，保留现有三个入口与设置界面。开发数据库仍是同机 WSL/Conda PostgreSQL；本机串口不经过服务端。

## 已实现

- 服务端登记设备及映射、新标签绑定、每份处方独立参数版本；实机禁止使用标记为模拟用途的参数。
- 任务绑定设备、终端与账号。数据库约束阻止同设备或同长者的并发有效任务；首次启动校验当前计划与新鲜标签观察。已开始任务使用完整冻结快照。
- Windows 原生执行宿主以独立 Dart Isolate 持有串口和 SQLite。命令意图、事件、状态与待同步队列先持久化；连接不发送动作，界面切换不销毁宿主。文件锁阻止第二个窗口获得执行权。
- 开仓后识别、参数后矩阵、累计计数与 FINISH 核对、同盘自动下一药、换盘重新识别并确认、暂停和恢复、当前开口调整、受控停止取消、断联核对及显式不记录删除。
- 已开始任务可在无 HTTP 同步时执行余下快照；恢复网络只补传事件。重启不会自动恢复或重发矩阵。未知命令结果、复位和矛盾反馈保留占用。
- 正常结束进入首页取盒提示；只有配置的有效离轨反馈持续稳定，才收仓，并在就绪反馈到达后释放。`NO CARD`、通用 ACK/DONE 均不能充当取盒就绪。
- 历史显示计划量、累计反馈量和批次完成依据，不伪造逐格实测。完整实机任务产生后续覆盖起点；模拟任务不会推进真实覆盖；取消撤销本次覆盖。

## 运行证据

- PostgreSQL 后端测试：24 项通过，含并发领取、原终端/账号限制、过期识别、旧计划启动、模拟参数阻挡实机、事件顺序/去重、覆盖及删除防重建。
- 本机运行模块：8 项测试通过，含双盘、暂停恢复不重发、超时、重启/复位、删除、启动参数途中取消，以及完成后反馈不污染补传队列。
- 原客户端回归：85 项通过；新增历史查询与桌面/窄屏执行交互：3 项通过。新测试检查历史查询的已结束过滤、暂停恢复、任务期间连接配置锁定、取盒提示与布局。渲染图在 `.tools/ui-review/terminal-1280.png`、`terminal-390.png`。
- `check_execution.dart` 已通过真实 SDK → HTTP → PostgreSQL → SQLite → 字节协议模拟机的双盘流程。最终复验两批各 4 颗、124 条事件，停止 HTTP 同步后完成换盘和取盒，再补传至 `completed`；模拟不推进实际覆盖。运行报告在 `.var/execution-check/latest.json`，仅含虚构数据。
- `check_terminal_host.dart` 已在 Windows 运行通过：实际 Isolate、SQLite、反馈回传、独占锁、COM 枚举（4 个候选，未打开真实串口）、宿主关闭。
- Windows Release 与 Web Release 已成功构建，OpenAPI/Dart SDK 无漂移检查通过；API 就绪检查为 ready，网页返回 200。原生窗口及登录页已打开检查。原生窗口中的全流程人工点击尚未验收；交互由 Flutter 控件测试验证，核心全流程由上述真实服务模拟联调验证。

复验命令从仓库根执行：

```powershell
.\scripts\backend.ps1 test
.\scripts\dart.ps1 packages/device_runtime test
.\scripts\flutter.cmd test
.\scripts\dart.ps1 apps/client run tool/check_execution.dart
.\scripts\dart.ps1 apps/client run tool/check_terminal_host.dart
```

## 实机事实与剩余边界

本轮没有连接实际 HC-06 或下发实机动作。按用户要求查阅现有报告：`.var/skip-probe-20261005.json` 记录历史 COM7、115200，停止收到 ACK，退出药物/开仓收到 ACK、DONE；历史仅监听报告没有在轨/离轨/就绪报文。旧版本构建报告明确未做硬件测试。这些报告不是当前端口、参数或新适配器实测证据；未读取旧代码。

用户确认名称通常为 `dispenser01` 格式。当天的出站 COM、稳定身份、每药转盘/舵机初值须现场核对；没有编造默认实机值。位置和反馈配置必须由操作者依据现场证据确认。缺少有效离轨/就绪反馈时，本版保留任务占用，不会自动假定取盒结束。

尚未交付或实测：实机机械位置与命令时序验收、跳过后继续/人工补齐及部分覆盖细化、药品图片上传、批量 PDF 标签、参数学习、历史分页/导出、Android RFCOMM/USB 与前台服务、锁屏/断电现场行为、生产安装包/备份恢复与长期负载验收。此交付是 Windows 上机联调版，不代表生产完整验收。操作步骤见 [Windows 测试指南](../windows-machine-test.md)。
