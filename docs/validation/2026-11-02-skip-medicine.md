# 2026-11-02 正式跳过功能与平板测试安装

目标：在正式执行中实现 R10，支持当前药、本盘该药整批人工确认和当前长者全部剩余药物跳过；遵循 04 已确认的停转 ACK、退出 ACK/DONE 顺序。分支 `codex/user-experience-optimization`，不读取或修改 legacy。

## 交付

- 执行页新增“跳过”；弹窗默认不勾选“将此药标记为已摆好”。弹窗期间暂停；取消恢复之前状态；全部剩余跳过始终不应用人工确认勾选。
- 命令绑定任务与批次。退出确认前不启动下一药、不提前开仓；缺应答及重启进入现场核对。同盘原先暂停则下一批不启动，跨盘仍重新识别与确认。
- 保存请求、停转/退出应答与最终结果；机器计数不被人工确认覆盖。历史区分机器完成、人工确认、跳过，以及整体部分完成/未完成。只有全部机器完成或人工确认的实机任务推进完整周期覆盖。
- FastAPI 模型新增结果列表及 `skip_protocol`，OpenAPI/Dart SDK 经脚本生成。旧快照默认空列表及协议 0；新版任务协议 1 才开放入口。无新增数据库结构迁移，发布须先服务端后客户端。
- 完整周期内任意日期时段的部分补齐、细粒度覆盖仍未实现；本轮整批人工确认范围仅为当前药盘当前药。
