# 2026-10-27 Android 执行宿主验证

目标：在已提交的 Windows 联调基线 `80293f4` 上推进 Android 平板版本，复用同一任务语义、协议和 SQLite 执行记录。初始实现阶段未连接真实 HC-06；同日现场进展见下方追加记录，分别标明用户观察和工具验证。

## 交付实现

- `TerminalSession` 为 Windows Isolate 与 Android 服务共用的串行命令/轮询宿主，平台只提供传输。已有任务或未确认的领取意图均阻止换连接和关闭宿主。
- Android `TerminalService` 持有独立 FlutterEngine、蓝牙连接与执行会话；界面通过 MethodChannel 读取状态、发送语义操作。UI 生命周期不再承担设备轮询和补传。
- 经典蓝牙 RFCOMM/SPP：从已配对设备选择地址，按需请求附近设备权限，连接不发动作；连接与写入有界超时，收包缓冲区有上限，失败不自动重发。
- `connectedDevice` 前台服务、隐藏业务信息的通知、任务范围的有超时 wake lock。切回 UI 读取最新快照；根页面系统返回和划掉最近任务均退到后台，应用内结束保留原受控停止流程。
- 本机 SQLite 保存在 `noBackupFilesDir/terminal`，应用自动备份关闭。后台补传使用生成的 SDK；令牌仅留服务内存，进程重启需要登录后再同步。
- 系统强制停止后读回任务并进入核对，不自动连接或发矩阵。用户于 2026-10-27 确认划掉最近任务继续后台运行，只通过应用内操作结束任务。
- 普通入口 `scripts/run-android.ps1` 构建/安装真实客户端；独立工程包 `com.pillxai.pillxai_client.runtimecheck` 专门验证模拟器，不能作为生产客户端。
