# 2026-10-26 NT 分支：账号、长者与处方接入

> 历史阶段记录：本报告中的多机构实现与测试已被用户随后要求的单工作区版本替代，不作为当前功能定义。当前接口、权限和迁移见 apps/api/README.md；其余当时验证结果保留。

## 交付范围

承接 M0，完成 M1 的真实资料切片。默认 Flutter 入口连接中央 API，登录、机构选择、长者列表与表单、处方保存/停用/恢复、版本查看、本人密码与院内账号管理不再依赖 DemoModel。三入口和现有表单视觉保留；生产摆药入口明确显示尚未接通。演示执行只在显式 `PILLXAI_DEMO=true` 构建中可用。

后端按 identity、residents、prescriptions 分模块，使用 PostgreSQL 事务和 Alembic 迁移。公开模型经 FastAPI → OpenAPI → Dart SDK 生成。客户端只引用 SDK，由 repository 映射展示模型，controller 持有单一机构的查询状态；页面不依赖后端内部或数据库。

## 已实现

- 12 小时可撤销会话；令牌仅在客户端内存，数据库仅保存令牌摘要。密码使用独立随机盐的 scrypt（N=16384、r=8、p=5），依据 [OWASP 配置](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) 和 [Python hashlib](https://docs.python.org/3.12/library/hashlib.html)。无默认公开密码，不保存用户输入密码。
- 平台管理员建机构及院内管理员；院内管理员建工作人员。工作人员默认可读，本院维护资料需要授权。所有按编号访问、搜索和版本读取均先校验机构。
- 修改密码、管理员重置密码及停用账号撤销相关会话；恢复账号不恢复旧令牌。账号管理记录操作人、动作、时间和版本。
- 长者稳定 UUID、姓名和选填床位；按 B09 仅去首尾空格，以完整非空床位在本院唯一。数据库唯一索引处理并发冲突；资料历史单独留存。
- 独立处方条目、院内药品身份、用药版本。停用、恢复沿用条目身份；改药品描述产生新的药品身份，旧版本保存原身份。当前没有跨条目学习参数共享。
- 原片剂量以精确字符串传输；半片每次 0.5 片，整片/整粒每格 0–255 整数，至少一个正用量，起止日期校验，未启用睡前格不可保存睡前需求。
- 客户端提交打开表单时的 revision；数据库原子比较并交换。冲突不覆盖他人数据，草稿仍留在表单；网络结果不明不自动重发。保存等待中禁用重复提交。
- 事务依赖使用 function scope，数据库成功提交后才发送成功响应。资料、处方及其版本同事务写入。
- 本机开发种子只显式创建空机构和随机凭据；无旧数据迁移。现场测试仍不打开真实串口。

## 当前限制

这是本机开发联调切片，尚未做公网 HTTPS、登录限流/生产安全加固、多院负载、备份恢复与生产部署验收。登录令牌不落盘，重启客户端需要重新登录。账号审计目前记录动作与版本，不提供完整管理审计页面。

机构时段与覆盖等设置的维护 API、药品目录复用选择、照片与药图上传、设备参数细分权限尚未接入；新机构睡前格默认关闭。生产计划、任务归属、真实执行、补传、执行历史、RFID、Android 宿主/锁屏仍属于后续阶段。处方版本不是摆药结果。

本轮未构建 Windows 安装包或 Android APK；Web 页不具备 COM 连接能力。Windows 实机继续使用独立 device_probe，当前出站 COM 和现场状态仍须核实。

## 复现

后端启动和凭据见 `apps/api/README.md`，客户端入口见 `apps/client/README.md`。

```powershell
.\scripts\backend.ps1 migrate
.\scripts\backend.ps1 seed
.\scripts\backend.ps1 serve
# 另开终端：
.\scripts\integration.ps1 -Business
.\scripts\verify.ps1 -IncludeUi
```

`integration -Business` 会新增明确命名的虚构联调资料，保留版本，不删除记录。原始本机日志在忽略目录 `.tools/m1-*.log`，凭据在 `.var/local-login.json`，不可提交。
