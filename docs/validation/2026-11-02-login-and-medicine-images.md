# 登录保持与药品图片

目标：工作人员登录一次后再次打开仍可恢复登录；在处方药物表单选择拍照或从文件上传药品图片。输入依据为 2026-11-02 用户要求，交互定义见 06，照片留存定义见 03。

## 交付内容

- 使用平台安全存储按服务器地址保存可撤销令牌，不保存密码。启动验证 `/auth/me` 并读取设置后进入工作区。网络失败保留令牌供重试，失效令牌清除；主动退出同时撤销服务器会话。服务器会话 30 天有效，每次成功恢复续期，过期、停用或改密后需重新登录。
- 新增/编辑药物的上传按钮提供拍照、从文件上传；预览、更换、移除、取消及保存失败均保护当前草稿。图片保存为经校验的 PNG 缩略图，通过处方和任务接口传递，已有任务保留原图片。API JSON 字段和 Dart SDK 同步生成，无新增数据库迁移。
- Android 拍照调用系统相机，从文件上传调用系统文件选择器。图片原文件不超过 10 MB，最长边处理至 512 像素。系统在相机打开期间回收进程时，重启提示重新填写未保存处方并选择图片，不错误绑定照片。
