# 2026-10-26 NT 分支 M0 基础切片验证

## 目标与范围

按 09 的计划开始实施：同机 WSL/Conda API、真实 PostgreSQL、生成式 Dart 契约、独立设备协议及 Windows 工程联调入口。分支从现有 `feat/NT-base` 创建为用户指定的 `NT`，保留此前计划文档修改。

这是 M0 的首个可运行基础切片。Android 服务宿主验证仍未完成；M1 真实账号/长者/处方、M2 计划归属、M3 生产执行状态机与补传、M4 完整流程均未完成。现有 UI 仍由演示模型驱动，新增 API SDK 已纳入 Flutter 依赖和验证入口。

## 环境与数据位置

- Windows：仓库内 Flutter/Dart 工具链，设备联调在 Windows 进程运行。
- WSL：Ubuntu-24.04，项目环境 `.tools/conda/backend`，Conda/Python 依赖锁见 `apps/api`。
- 用户单独授权的 PostgreSQL 数据目录：`/home/jiale/Workspace/Pillxai-Dispener/.var/postgres`。已实际初始化并验证 0700 权限；原 Windows 挂载目录 chmod 后仍为 777，未用作数据库数据目录。
- API `127.0.0.1:8000`，数据库 `127.0.0.1:5432`，仅本机。未改全局 PATH、防火墙、驱动、系统服务或已有 Conda 环境。
- PostgreSQL 只建立新开发库 `pillxai_dev` 和测试库 `pillxai_test`；本轮仅存虚构契约样例，不含旧业务数据。
- 本机诊断样例在 `.var/device-probe/diagnostics.sqlite`，明确标记 simulator。
