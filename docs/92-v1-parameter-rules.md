# V1 参数依据与差异

更新：2026 年 10 月 27 日。

**当前决定：新版参数与学习规则先沿用 V1 Home，后续再优化。**STM32 在单次摆药内自行调速，上位机只设置初速度。完整有效规则、流程图和算例统一见 [04 · 新参数与学习策略](04-device-contract.md#新参数与学习策略)。

本文只保留来源和差异，供复核。参数归属、版本与整半片变化按 [R14](02-workflows-and-rules.md#r14-每份处方独立的出药参数)；旧代码和旧已学习数据不迁入新版。本轮为文档更新，不代表新版自动学习已接入或实机验收通过。

## 1. 采用哪组配置

| 项目 | V1 参数声明 | V1 Home 场景 | 新版当前采用 |
| --- | --- | --- | --- |
| 自动学习 | 关闭 | 开启 | 开启 |
| 默认转盘初速度 | 0.3 | 0.2 | 0.2 |
| 默认舵机值 | 0.7 | 0.7 | 0.7 |
| 最少有效样本 | 7 | 7 | 7 |

其余公式系数和动态限幅在声明与 Home 中一致。采用 Home 配置，不采用参数管理对象缺失时的 `0.3 / 0.7` 回退。[S1、S2、S3]

## 2. 核对时发现的差异

| 容易误读的地方 | 核对结果 |
| --- | --- |
| 旧名称“转盘速度” | 用户确认它是上位机设置的初速度；实际运行速度由 STM32 在批次内调整 |
| 旧名称“舵机角度” | 使用 0–1 设备刻度，数值越小开口越大；不标为角度或百分比 |
| 部分注释写“平均脉宽” | 实际取中位数；偶数个取中间两数的平均 |
| 注释“0.10 全开” | 学习公式实际下限为 0.08、上限为 0.98；不据注释推定机械极限 |
| 调试电机范围 0.1–1.4 | 主流程学习出的下次初速度限制在 0.15–0.36；不能混用 |
| 保存接口注释写了数值范围 | V1 专用保存入口未执行该范围校验；不作为新版校验依据 |
| 界面显示两位小数 | 不代表公式或参数保存统一舍入到两位 |
| “关闭学习” | V1 会使用默认参数组，不只是冻结历史值；当前保持这一语义 |
| 手动调整 | V1 使用最后一次成功值和既有权重；当前保持，详细分支见 04 |

脉宽物理单位仍未确认，保留原值。分段采样、人工权重、开关语义及候选试用的改进留到后续，不改变当前规则。

## 3. 通用设置的历史观察

V1 一次摆药天数默认 7，允许整数 1–7；越界旧值回退为 7。提醒阈值默认 2，实际要求正整数，未落实提示中的“0–14”范围。服务地址要求非空、去除首尾空白，并以 `http://` 或 `https://` 开头。[S7]

这些设置不参与出药学习。新版通用设置以 [00](00-scope-and-defaults.md#默认设置)为准。
